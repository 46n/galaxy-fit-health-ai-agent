Architecture

flowchart LR
    A[Galaxy Fit3] --> B[Samsung Health]
    B --> C[Health Connect]
    C --> D[Life Dashboard Companion]
    D --> E[Apps Script Web App]
    E --> F[OpenAI Responses API]
    F --> G[Telegram]
    E -. optional .-> H[Discord Bot REST API]

What It Handles

Webhook ingest

Receives Life Dashboard Companion JSON through an Apps Script Web App with a shared secret.

Metric parsing

Extracts steps, sleep, heart rate, oxygen saturation, and exercise when those fields are present.

Safe outputs

Sends Telegram by default and can optionally post through a Discord bot without using webhooks.

Safety Boundary

This is a wellness automation, not medical software. The agent avoids diagnosis, medication advice, and clinical treatment plans, and it reminds users that wearable data can be imperfect.

Built for personal automation with no secrets committed to the repository.
